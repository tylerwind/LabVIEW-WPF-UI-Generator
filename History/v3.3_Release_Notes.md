# LabVIEW WPF UI Generator - v3.3 Release Notes
*发布日期：2026-08*

## 🚀 从“页面布局”到“复杂工业数据架构与全域热切换”的纵深跃进

v3.3 是项目迈向复杂工业组态、高频数据交互与极限运行稳定性的里程碑版本。本次更新不仅推出了融合树形与多列表格的重量级构件 **TreeList**，还在单/多列树节点深层遍历、全控件全域主题运行时热切换、DataGrid 动态状态徽章、LED 自由形态变形、以及多线程与色彩同步稳定性上完成了全方位闭环升级。

---

### 1. 旗舰新构件：多列树形列表控件 (TreeListPanel / TreeListControl)
为满足复杂设备拓扑、配方参数管理、生产批次追溯与层级化测量数据的展示需求，v3.3 推出全新第 17 款核心构件 `TreeList`（多列树形列表）。
* **树表融合架构**：将层级树（Tree）的折叠展开与节点嵌套能力，与数据网格（DataGrid）的多列展示能力深度融合。
* **灵活列宽与自适应分配**：
  * 支持通过 API (`SetColumns`) 动态定义多列表头名称与初始宽度；
  * 支持固定像素列宽与自适应弹性列宽混合分配，并自动预留滚动条边缘缓冲。
* **丰富的节点操作与懒加载**：
  * 支持节点动态增删改查 (`AddNode`, `RemoveNode`, `ClearNodes`, `UpdateNode`, `UpdateNodeColumnTexts`)；
  * 支持异步懒加载虚拟节点 (`hasDummyChild`)，展开时按需动态拉取下级数据；
  * 支持复选框 (`CheckBox`) 与自定义节点图标 (`IconPath`)。
* **节点数据与父节点溯源 API 开放**：
  * 开放获取节点指定列/全部列文本方法：`GetNodeColumnTexts` (字符串数组)、`GetNodeColumnTextsUTF8` (防乱码字节流)、`GetNodeColumnText` (指定列文本)；
  * 开放父节点溯源方法：`GetParentNodeId` (父节点 ID)、`GetParentNode` (父节点实例)、`GetParentNodeColumnTexts` (父节点列内容)；
  * `TreeListNode.ParentNode` 属性对外开放，支持树形结构的向上无缝回溯。
* **工业级事件总线**：
  * 具备精准显式委托，提供 `NodeSelected`（选中）、`NodeDoubleClicked`（双击）、`NodeChecked`（勾选）、`NodeExpanding`（展开）以及 `NodeMenuClicked`（右键菜单点击）等完整事件回调。

### 2. 全域主题运行时热切换与底色无缝融合 (Runtime Theme Switch & Background Sync)
* **10 套高颜值预设工业主题**：
  * 内置 5 套商务高级主题（松石黛青、钛金极简、黑金商务、北欧冰原、羊绒暖灰）；
  * 内置 4 套多巴胺活力主题（活力甜橙、柠檬海盐、浆果抹茶、赛博粉蓝）及经典默认主题。
* **全控件双模秒级热切换**：
  * `UpdateStyleFromJson` 支持传入 **JSON 文件绝对路径** 或 **JSON 纯文本字符串**，无需重启程序，一键实现 17 类控件全局重绘。
* **多线程 UI 安全与 0 崩溃保障**：
  * 彻底重构全控件 `ApplyStyleDictionary` 与 `SyncWpfBackground` 调度机制，加入 `Dispatcher.CheckAccess()` 跨线程调度与 Freezable 资源所有权保护，根治 LabVIEW 多线程调用下的崩溃问题。
  * 修复 XAML 资源动态赋值类型错配，保障高饱和度多巴胺主题在极限条件下的极速切换稳定性。
* **容器底色与 LabVIEW 窗口 100% 融合**：
  * 单列树、多列树、滑动杆、开关、表格等全部 17 类面板在初始化与主题热切换时，均自动同步更新 WinForms Panel 的 `BackColor` 与 WPF 内部根画刷，消除控件边缘色差与白底方框。

### 3. DataGrid 单元格徽章状态渲染与单格极速刷新
针对工业上位机常见的高频状态监测与告警标识场景，重构了 `DataGrid` 的渲染引擎：
* **内嵌徽章标记语法**：
  * 支持使用 `[#HEX_OR_COLOR]Text` 嵌入式语法（例如 `[#10B981]OK`、`[#EF4444]NG`、`[#F59E0B]Warning`）；
  * 自动拦截列生成并渲染为带高光和流光圆角的状态胶囊徽章（Badge），普通文本保持原样呈现。
* **单单元格响应式局部更新**：
  * 新增 `UpdateCell(int rowIndex, int colIndex, string value)` API，支持直接精确定位更新单个单元格内容，无需全量重刷整个数据源，极大降低 UI 渲染负载。
* **LabVIEW 色彩互操作**：
  * 提供 `FormatBadge(string text, int colorValue)` 静态辅助方法，支持传入 LabVIEW 原生 32 位整型（U32/I32）色彩数值进行格式化。

### 4. 单列树形控件功能增强 (TreePanel / TreeControl)
* **节点信息与父节点回溯 API**：
  * 开放 `GetNodeText` / `GetNodeTextUTF8` 获取节点名称；
  * 开放 `GetParentNodeId` / `GetParentNode` 支持向上遍历父级节点；
  * `TreeNode.ParentNode` 设为公开属性。
* **交互细节优化**：
  * 修复单列树鼠标选中行背景色高亮响应；
  * 优化初次加载底色与宿主窗口背景自动一致。

---

### 5. LED 指示灯形态参数化与间距优化
* **打破正圆限制**：底层重构为参数化 `Border` 多层发光与投影体系，形态完全受 `CornerRadius` 控制。
* **自由形态变形**：支持根据工程设计在“正圆指示灯”、“圆角胶囊灯”、“方块指示灯”与“长条状态指示器”之间自由变形，并在运行时支持动态样式热切换。
* **边距精修**：精简了指示灯与外部容器的冗余边距，适配紧凑型工业监控看板布局。

---

### 6. 技术规范与零代码闭环保障
* **目标框架**：.NET Framework 4.0 / C# 5.0 规范，保证在 Windows 7 / 10 / 11 及各类工控机环境开箱即用。
* **事件回调机制**：所有事件回调均采用原生值类型或字符串/字节流展开，杜绝 .NET 引用句柄泄漏风险。
* **色彩双通道**：所有颜色属性全面支持 HEX 字符串（如 `"#059669"`）与 LabVIEW 32 位数值（RGB 数值）双向互通。
* **防乱码保障**：核心文本 API 均提供 UTF-8 字节流接口，彻底杜绝中文字符乱码。

## ✨ 已支持的全量核心控件矩阵 (v3.3)
本项目目前已内置并在底层完全打通 LabVIEW 事件与双通道色彩重绘回调机制的 **17 款** 高频工业控件：

1. `TextInput` - 文本输入框 (支持自适应与只读)
2. `NumericDisplay` - 数值输出框 (带独立单位格式渲染)
3. `Slider` - 阻尼滑动杆 (丝滑流体色彩)
4. `Button` - 流光动画按钮 (科技感触发)
5. `IconButton` - 拟态图标按钮 (支持图标与标签聚合)
6. `ComboBox` - 现代下拉列表 (高度可定制)
7. `LED` - 极简指示灯 (✨ v3.3 升级 - 支持圆角自由变形与间距精修)
8. `ToggleSwitch` - 拟态物理感开关
9. `ProgressBar` - 动态渐变进度条
10. `ChartDisplay` - 折线图/多通道波形图 (带悬浮数值观测卡盘)
11. `PieDisplay` - 精致动态饼图 (中空光影渲染)
12. `GaugeDisplay` - 环形仪表盘 (动态极值重绘)
13. `DataGridDisplay` - 现代数据表格 (✨ v3.3 升级 - 单元格状态徽章与单格更新)
14. `TreeDisplay` - 树形展示面板 (✨ v3.3 升级 - 父节点回溯与选中高亮)
15. **`TreeListDisplay` - 多列树形列表 (✨ v3.3 NEW - 树表融合、独立列宽与列内容/父节点遍历)**
16. `SidebarNav` - 拟态侧边导航栏 (支持 UI 调度与 Logo 定制)
17. `TopbarNav` - 拟态顶边导航栏 (水平流体导航与指示器)
